# Nova Browser updates

Nova Browser uses `electron-updater` with a generic update provider.

## One-time setup

Before the first release build, replace the placeholder in `package.json`:

```json
"publish": {
  "provider": "generic",
  "url": "https://YOUR-UPDATE-HOST.example.com/nova/"
}
```

The update directory must publish the files generated by `electron-builder`, including:

- `latest.yml`
- `Nova Browser Setup <version>.exe`
- the generated blockmap file

Keep the installer and `latest.yml` in the same update directory.

## Release workflow

1. Change `version` in `package.json`, for example `1.0.4`.
2. Run `npm install`.
3. Run `npm run dist`.
4. Upload the generated installer, blockmap and `latest.yml` to the configured update URL.
5. Existing installed Nova Browser users can open **Check for updates**.
6. If a newer version exists, Nova downloads it.
7. When the download finishes, the button changes to **Restart & install**.
8. Nova closes, installs the new version, and starts again.

If no newer release exists, the browser reports:

> Nova Browser <current version> is up to date.

### Important

The updater is deliberately disabled for development (`npm run browser`). It only checks for updates in a packaged/installed build. Never put API keys in the update files or installer.
